# Working on the Cutting Room

**Read [`CLAUDE.md`](CLAUDE.md). It is this file.** Everything about how to
work here — the house rules, the architecture, and the list of faults that
must not be undone — lives there, and it applies whichever assistant is
reading it. The name on the file is an accident of which tool was used first.

⚠️ **This file used to be a second copy of it**, kept for a different
assistant, and the two had drifted **213 lines apart** inside three days: one
of them said fifteen pieces of work where the other said twenty-one, and it
was missing the last five faults entirely — including the two about lists that
cannot be shortened and the one about a check that asks the easy question.

That is the fault this codebase warns about more than any other, arriving in
the documents themselves: **anything written down twice will disagree with
itself, and you will not know which copy you are believing.** So there is one
copy now, and this is a signpost to it.

Then read [`BACKLOG.md`](BACKLOG.md) — its *NOW* section is the live list.

For using the room rather than working on it: [`GUIDE.md`](GUIDE.md) is the
walk-through and [`ROOM.md`](ROOM.md) is the manual.
